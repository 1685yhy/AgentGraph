# 写作风格指南

## 语气 (Tone)
- 我们是什么: ___ (如: 专业但不冷漠，亲切但不随意)
- 我们不是什么: ___

## 用词规范

| ✅ 推荐 | ❌ 避免 | 原因 |
|---------|---------|------|
| 使用 | 利用 | 更直接 |
| 可以 | 能够 | 更口语化 |
| ___ | ___ | ___ |
| ___ | ___ | ___ |
| ___ | ___ | ___ |

## 格式规范
- 段落: ≤ 3 句话
- 标题: 陈述句，不用问句
- 列表: 3-7 项
- 链接: 描述性锚文本，不用"点击这里"
- 图片: 必须有 alt 文本
