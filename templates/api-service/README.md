# API 服务 模板

## 这是什么

AgentGraph API 服务 项目模板。初始化后自动配置 Agent 团队和开发流程。

## 使用

```bash
guild init --template api-service ./my-project
cd my-project
guild plan "你的需求描述"
```

## Agent 团队

运行 `guild capability api-service` 查看完整 Agent 列表和模块。

## 流程

1. 架构设计 → 后端架构师
2. 数据建模 → 数据库专家
3. 安全加固 → 安全工程师
4. 质量验证 → QA 测试 + 压测
5. 交付 → 运维部署
