# 企业官网 模板

## 这是什么

AgentGraph 企业官网 项目模板。初始化后自动配置 Agent 团队和开发流程。

## 使用

```bash
guild init --template corp-site ./my-project
cd my-project
guild plan "你的需求描述"
```

## Agent 团队

运行 `guild capability corp-site` 查看完整 Agent 列表和模块。

## 流程

1. 需求定义 → 产品经理
2. 品牌调性 → 品牌守护者
3. 创意设计 → 创意总监 + UI设计师
4. 开发实现 → 前端工程师
5. 内容与SEO → 内容创作者 + SEO专家
6. 交付 → 产品经理验收上线
