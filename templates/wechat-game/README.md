# 微信小游戏 模板

## 这是什么

AgentGraph 微信小游戏 项目模板。基于 PhaserJS 3.60，初始化后自动配置 Agent 团队和开发流程。

## 使用

```bash
guild init --template wechat-game ./my-project
cd my-project
guild plan "你的需求描述"
```

## Agent 团队

运行 `guild capability wechat-game` 查看完整 Agent 列表和模块。

## 流程

1. 玩法设计 → 游戏设计师
2. 开发实现 → 游戏程序（客户端）+ 美术/UI/音频（并行）
3. 变现设计 → 变现设计师
4. 质量验证 → 游戏QA（真机测试 + 性能）
5. 交付 → 游戏制作人（提审 + 发布）
