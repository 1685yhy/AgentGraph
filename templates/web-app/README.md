# Web 应用 模板

## 这是什么

AgentGraph Web 应用 项目模板。初始化后自动配置 Agent 团队和开发流程。

## 使用

```bash
guild init --template web-app ./my-project
cd my-project
guild plan "你的需求描述"
```

## Agent 团队

运行 `guild capability web-app` 查看完整 Agent 列表和模块。

## 流程

1. 需求定义 → 产品经理
2. 用户研究 → 用户研究员
3. 界面设计 → UI设计师
4. 开发实现 → 前端工程师 + 后端架构师（并行）
5. 质量验证 → 安全审计 + QA 测试
6. 交付 → 运维部署
