# 营销落地页 模板

## 这是什么

AgentGraph 营销落地页 项目模板。初始化后自动配置 Agent 团队和开发流程。

## 使用

```bash
guild init --template landing-page ./my-project
cd my-project
guild plan "你的需求描述"
```

## Agent 团队

运行 `guild capability landing-page` 查看完整 Agent 列表和模块。

## 流程

1. 需求定义 → 产品经理
2. 视觉设计 → UI设计师
3. 文案素材 → 内容创作者
4. 开发实现 → 前端工程师
5. 优化与SEO → 增长黑客 + SEO专家
