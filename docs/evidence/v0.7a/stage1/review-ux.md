## 四、视觉/质量审计（实测）

**优点**
- 设计系统完整：统一圆角（20/12）、间距刻度（8/16/24/40/64）、衬线标题（品牌/节标题）+ 无衬线正文的双字体体系、四级字号清晰（80→32→22.4→19.2→15.2px）；Hero 285px 高、节间距 80px，呼吸感良好
- 对比度（WCAG 公式实测）：正文 14.87:1、菜单描述 6.35:1、价格 12.31:1，全部远超 AA；Hero 品牌字约 5.8–8.5:1
- 无障碍投入超出需求：`role=dialog`+`aria-modal`+`aria-labelledby`、焦点管理与归还、`:focus-visible` 描边实测生效（3px 暖橙）、label/for 全关联、lang=zh-CN、meta title/description 齐全
- 文案零占位：无 lorem、无 TODO、无死链（实测 0 外部链接、0 图片可断），品牌名/门店/产区命名自洽（山屿咖啡 · 云南保山/普洱/临沧）
- 预约按钮 52px 高，触控达标

**建议（非阻断）**

| # | 级别 | 问题 | 证据 |
|---|---|---|---|
| 1 | 建议（较重要） | 弹窗表单输入框高度仅 **19px**（无 padding 样式，浏览器默认）、宽度约 181px 未撑满弹窗（弹窗 338px 宽）；弹窗按钮高 40px。移动端触控目标低于 44px 推荐值，输入框显局促 | 实测 `.modal-box` 内 input 高 19px 宽 181px；`.modal-actions` 按钮 40px |
| 2 | 建议（较重要） | 白字按钮在暖橙底 #c97b4a 上对比度 **3.27:1**，未达 WCAG AA 4.5:1（按钮文字 17.6px 粗体，略低于大字号阈值 18.66px；属暖色系常见问题） | 按 WCAG 公式实测计算 |
| 3 | 建议 | 菜单描述 0.95rem=15.2px，低于常见 16px 正文最小值，移动端阅读偏小 | 计算样式实测 |
| 4 | 建议 | 成功反馈用 `alert()`、校验提示亦为原生 alert，且无真实后端（源码注释 L552 自认「模拟提交」）。静态落地页可接受；正式上线应换内联成功态/toast + 真接口 | 源码 L535-560 |
| 5 | 建议 | `.story-section { padding: 40px 0 }` 在层叠上**覆盖**了 `.container` 的水平内边距（0 24px）：375px 下故事区容器贴边（实测 x=0→375），仅靠 `.story-text` 自带 16px 内边距兜底；中窄屏视觉无碍但属样式隐患 | 实测 storyLeft=0/storyRight=375；源码 L246-251 与 L65-69 |
| 6 | 建议 | 弹窗表单未用 `<form>`（Enter 不触发提交）、按钮无 `type` 属性（当前无表单故无副作用，纯语义完善） | 源码 L491-500 |
| 7 | 建议 | 门店区 ☕ 以 emoji 文字作装饰（opacity 0.2），渲染依赖平台 emoji 字体，跨端观感不一；Hero 区为纯文字+渐变、无照片。真实咖啡品牌落地页若配产品/空间摄影，温暖质感会显著提升（超出本次需求范围，仅建议） | 源码 L470-472 |
| 8 | 建议 | 320px 下 Hero 品牌字 44.8px，实测无溢出（字距已收敛），但 4 字品牌在超小屏仍偏满，可考虑再降一档；另有 `viewport-fit=cover` 已声明但未用 `env(safe-area-inset-*)`（页面无底部固定元素，实际影响可忽略） | 源码 L398-406、L5 |
