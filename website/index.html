安装指南

每个工具一条命令

AgentGraph 支持四种 AI 编码助手，任你选择。

将所有智能体安装为 Claude Code 智能体身份。每个智能体成为一个可直接调用的自定义 Claude 模式。

$ ./scripts/install.sh --tool claude-code

安装为 Cursor 规则（.mdc 格式）。智能体以可组合的 Cursor 规则形式呈现，用于 AI 辅助编辑。

$ ./scripts/install.sh --tool cursor

安装为 GitHub Copilot 智能体定义。智能体被添加到你的 Copilot 配置中，用于内联辅助。

$ ./scripts/install.sh --tool copilot

安装为 Windsurf 规则。所有智能体被编译到单个 .windsurfrules 文件中，提供全面的 AI 支持。

$ ./scripts/install.sh --tool windsurf
设计哲学

AgentGraph 的独特之处

大多数 AI 智能体只是通用的提示词模板。AgentGraph 的智能体是精心设计的角色， 拥有结构化的观点、边界和自主性。

💭

反常识观点

每个智能体都附带一个强有力的、有理有据的观点，挑战行业正统。 不是为了博人眼球——而是通过迫使团队捍卫自己的假设来激发更好的决策。 比如坚持 CI 应在 10 分钟以内的 DevOps 工程师，或者说大多数 MVP 既不最小也不可行的产品经理。

⚡

冲突偏好

智能体不仅仅是同意——它们会提出异议。每个智能体都有定义的冲突风格： 何时升级、何时妥协、什么情况值得一票否决。品牌守护者会阻止那些 用长期信任换取短期指标的增长黑客行为。那不是意见不合—— 而是系统按设计在运行。

👁️

盲点认知

每个智能体都知道自己的短板。盲点被明确列出——比如忽视定性信号的 数据分析师，或者优先考虑美学而非可访问性的 UI 设计师。 通过暴露局限性，这个框架将弱点转化为协作机会，并防止越界。

🎯

决策权限

并非所有观点都同等重要。每个智能体都有定义的自主区域——创意总监的 品位判断超越共识，技术文档工程师的命名约定具有约束力。决策权限 消除了委员会式的决策泥潭，并赋予每个智能体清晰的所有权边界。
