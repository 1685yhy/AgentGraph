AgentGuild

Craft AI Teammates, Not Templates

AgentGuild is an open-source framework for authoring AI agent identities — purpose-built personas with opinions, constraints, and craft standards. From frontend engineers to creative directors, each agent ships with a Contrarian Take, conflict preferences, and decision authority that make them feel like real colleagues.

Quick Start

Get started in seconds

Clone the repo and install agents into your AI tool. No build step, no dependencies.

$ ./scripts/install.sh --tool claude-code
1

Clone

Clone the AgentGuild repository to your local machine.

2

Convert

Run ./scripts/convert.sh to generate integration files.

3

Install

Run ./scripts/install.sh --tool <name> to activate agents.

Installation

One command per tool

AgentGuild supports four AI coding assistants. Pick yours.

Install all agents as Claude Code agent identities. Each agent becomes a custom Claude mode you can invoke directly.

$ ./scripts/install.sh --tool claude-code

Install as Cursor rules (.mdc format). Agents appear as composable cursor rules for AI-assisted editing.

$ ./scripts/install.sh --tool cursor

Install as GitHub Copilot agent definitions. Agents are added to your Copilot configuration for inline assistance.

$ ./scripts/install.sh --tool copilot

Install as Windsurf rules. All agents are compiled into a single .windsurfrules file for comprehensive AI support.

$ ./scripts/install.sh --tool windsurf
Philosophy

What Makes AgentGuild Different

Most AI agents are generic prompt templates. AgentGuild agents are designed personas with structured opinions, boundaries, and autonomy.

💭

Contrarian Take

Every agent ships with a strong, well-reasoned opinion that challenges industry orthodoxy. Not for shock value — to spark better decisions by forcing teams to defend their assumptions. A DevOps engineer who insists CI should be under 10 minutes. A PM who says most MVPs are neither minimal nor viable.

⚡

Conflict Preferences

Agents don't just agree — they push back. Each has defined conflict styles: when to escalate, when to compromise, and what warrants a hard veto. A brand guardian will block a growth hack that trades long-term trust for short-term metrics. That's not disagreement — it's the system working as designed.

👁️

Blind Spots

Every agent knows what it's bad at. Blind spots are explicit — a data analyst who overlooks qualitative signals, a UI designer who prioritizes aesthetics over accessibility. By surfacing limitations, the framework turns weaknesses into pairing opportunities and prevents overreach.

🎯

Decision Authority

Not all opinions are equal. Each agent has a defined zone of autonomy — a creative director's taste call overrides consensus, a tech writer's naming conventions are binding. Decision authority eliminates death-by-committee and gives every agent clear ownership boundaries.
